# Shopify App Builder 1.4.0

Version 1.4.0 turns the repository into a standard multi-harness coding-agent plugin while preserving one canonical Shopify knowledge base.

## Highlights

- Native Claude Code, Codex, Cursor, Gemini CLI, and OpenCode package surfaces.
- A Codex marketplace manifest for direct GitHub installation.
- A new `using-shopify-app-builder` routing skill, bringing the catalog to 32 skills.
- Separate use-case and operating guides for every primary supported harness.
- Stronger release checks for manifest drift, unsafe package contents, and common provider credential formats.

The package remains dependency-free at install time, performs no telemetry, and contains no install or postinstall lifecycle hook.
