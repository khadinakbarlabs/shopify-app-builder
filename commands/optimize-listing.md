# Optimize App Store Listing

You are crafting and optimizing the Shopify App Store listing for maximum discoverability, merchant trust, and conversion.

## Discovery Optimization

1. **Title and keyword strategy**
   - Craft title: [Primary Keyword] + [App Type] (60 char max)
   - Example: "Inventory Analytics - Real-Time Stock Tracking"
   - Front-load highest-volume keywords (research Google Trends + App Store search volume)
   - Avoid keyword stuffing (App Store algorithm penalizes over-optimization)
   - Reference skill: SEO and discovery (05_appstore_strategy.md)

2. **Description copywriting**
   - Write 200-300 word description with problem-solution-benefit flow
   - Lead with merchant pain point ("Reduce inventory write-offs by 40%")
   - Emphasize ROI and time savings (core merchant triggers)
   - Include 3-5 key features with business outcomes, not technical specs
   - Add call-to-action ("Install free trial" or "Schedule demo")
   - Reference skill: messaging pillars (05_appstore_strategy.md)

3. **Category and tagging**
   - Select primary category based on category saturation analysis
   - Add secondary tags (max 5) for cross-discovery
   - Avoid oversaturated primary categories if undersaturated secondary exists
   - Use messaging pillars: efficiency, revenue-impact, ease-of-use
   - Reference skill: categorization strategy (05_appstore_strategy.md)

## Trust and Conversion

4. **Pricing transparency and reviews**
   - Clearly display pricing: freemium, tiered, or usage-based model
   - Include trial duration (14 days recommended for enterprise features)
   - Highlight number of active installs (social proof)
   - Monitor reviews and respond to negative feedback (>4.5 star rating target)
   - Reference skill: monetization presentation (05_appstore_strategy.md)

5. **Screenshots and visuals**
   - Use 5-6 high-quality screenshots showing core value propositions
   - Add captions to each screenshot highlighting benefits
   - Include app icon (256x256px, clear and memorable)
   - Create demo video showing workflow (optional but improves conversion)
   - Ensure screenshots optimized for merchant merchant context (not developers)

6. **Built for Shopify certification**
   - Complete certification checklist: API scopes justified, OAuth implemented, webhooks working
   - Ensure app meets performance standards: page load <3s, Admin API response <2s
   - Provide 30-day money-back guarantee or equivalent promise
   - Submit audit-scopes justification document with submission
   - Reference skill: Built for Shopify qualification (05_appstore_strategy.md)

## Pre-Submission Verification

7. **Final listing review**
   - Verify all spelling and grammar in description
   - Confirm pricing matches production billing configuration
   - Check that app functions flawlessly in development admin
   - Validate OAuth and webhook configuration complete
   - Test app installation flow as new merchant
   - Reference skill: submission checklist (05_appstore_strategy.md)
