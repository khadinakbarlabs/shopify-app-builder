# Shopify App Builder 1.3.0

The first public, security-reviewed release of Shopify App Builder packages 31 portable Agent Skills for building, auditing, launching, and growing Shopify apps with Claude Code, Codex, Cursor, OpenCode, Command Code, and compatible AI coding agents.

Highlights:

- Portable `SKILL.md` catalog plus Claude Code commands and specialist agents
- Dependency-free npm installer with project and global targets
- Claude and Codex plugin manifests with public marketplace metadata
- Credential, personal-path, symlink, and package-content release gates
- Recoverable Shopify cache reset instead of destructive deletion recipes
- Current Shopify REST/GraphQL limits, revenue-share guidance, and evidence-qualified Built for Shopify benefits
- MIT license, public security policy, privacy statement, terms, compatibility matrix, and contribution guide

This community project is not affiliated with or endorsed by Shopify.
