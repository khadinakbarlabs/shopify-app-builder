# Claude directory review — v2 local skills

This release declares skills, commands, agents, and publisher metadata in the native Claude manifest, using only keys Claude Code reads. It has no .mcp.json, MCP runtime or automatic authentication binding. A historical scan for the v1 URL-only server is not a current v2 configuration finding.

There is no root plugin.json; Claude loads .claude-plugin/plugin.json. The package ships no artwork files. Listing links and the listing icon are kept by the directory from the original submission rather than declared in the manifest; validate with the current supported CLI.

Directory publication, icon approval and creation-time Listing metadata are separate states. Previous desktop evidence showed a serving version newer than the saved Listing snapshot; do not promise that pushing source updates all snapshot fields. Contact the directory team to correct a frozen saved record instead of delisting/recreating it automatically.

Validate this exact version and inspect the actual serving version/review results after any upload or GitHub update. No local validator proves directory approval.
