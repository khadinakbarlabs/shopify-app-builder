# Claude directory review — v2 local skills

This release declares skills, commands, agents, publisher metadata and a static icon in the native Claude manifest. It has no .mcp.json, MCP runtime or automatic authentication binding. A historical scan for the v1 URL-only server is not a current v2 configuration finding.

The portable root Agent Plugins manifest is intentional for other hosts; Claude loads .claude-plugin/plugin.json. Static PNG branding is never executed by a helper. Directory-only policy fields may be ignored by older Claude Code versions while still used by the directory; validate with the current supported CLI.

Directory publication, icon approval and creation-time Listing metadata are separate states. Previous desktop evidence showed a serving version newer than the saved Listing snapshot; do not promise that pushing source updates all snapshot fields. Contact the directory team to correct a frozen saved record instead of delisting/recreating it automatically.

Validate this exact version and inspect the actual serving version/review results after any upload or GitHub update. No local validator proves directory approval.
