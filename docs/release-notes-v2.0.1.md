# v2.0.1 — directory review and verified-publisher validation

The release validator now accepts the approved verified business name in explicit public publisher fields, while retaining rejection of unknown variants, unrelated identity text and credential shapes. Regression coverage verifies those boundaries.

The local skills package still has 35 skills, 13 guided command definitions and 8 specialist-agent definitions. It adds no MCP server, hosted endpoint, account binding or paid automatic action.

Claude directory-only URL/icon fields remain intact because they are documented listing fields. Portable-manifest and static-PNG notices are documented for reviewers; this release does not claim they will disappear. Original-submission metadata snapshots, icon approval, OpenAI automated-service availability and developer legal declarations are external directory gates, not package runtime fixes.
